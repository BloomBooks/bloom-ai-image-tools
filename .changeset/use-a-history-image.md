"Use this Image" now puts the picture into the book slot the user is working on, so an image
picked out of History can actually be used. The action used to route by the slot stored on the
image itself, which for a history image is whatever page it was originally made for: the button
either never appeared, or it quietly replaced a different page's image. A result that came out of
a run still goes to the slot that run was for.
